# Kodekloud 100 Days of DevOps

My documentation from the KodeKloud 100 Days of DevOps Challenge. Each md file covers the task, the problems I ran into, the solution, and the tools/commands used.

## About

100 days of hands-on DevOps practice: Linux, Git, containers, orchestration, CI/CD, IaC, cloud, and scripting. Every folder is a self-contained writeup of that day's task.
